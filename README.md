# Production-Working-Hours-Analysis---Excel
## Project Purpose
To evaluate labor efficiency, resource allocation, and budget performance across production divisions, job titles, and global locations. By analyzing the variance between planned hours, actual worked hours, overtime, and shortfalls, the project aims to identify operational bottlenecks, control labor expenditures, and optimize workforce scheduling.
